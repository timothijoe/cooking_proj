# 实体设备接入与身份确认

真机配置不能只依赖代码默认值。连接前应记录：机器人 IP、SDK A/B 到物理左右臂的映射、
Wuji USB 枚举序列号、产品 SN、手性、固件、关节错误码、温度、工具安装和坐标方向。

旧项目曾记录两组不同 Wuji 序列号：早期左手默认 USB 序列号 `365939643134`；2026-08-26
现场枚举到实体左手 `344D345D3533`。这证明硬编码默认值不可靠。教程保留旧值仅用于追溯，
每次运行都应显式传入现场读取的序列号。

旧左手套 `WG1JA03260502041` 使用 `192.168.10.150:50001`。当主机只有
`192.168.1.0/24` 地址时，广播扫描可能发现设备，但定向连接会被错误路由到 Wi-Fi。应先用
`ip route get` 和 `ping` 验证目标接口与源地址，再连接 Studio 或 SDK。同一手套/手不能被
Studio、SDK 和 ROS 同时拥有。

设备身份、网络路由或控制器状态改变都属于现场条件，不应写成跨机器永久默认值。相关人工
步骤见[Wuji 手套网络教程](../../../../tutorials/hardware/wuji_glove_network.md)。
