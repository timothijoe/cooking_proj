# 独立倒手参考环境：首个可运行版本

2026-09-18。对应 [环境设计](regrasp-microskill-env-design.md)。本文描述参考控制器与交互原型，**这个入口不加载 RL，也未连接真机**。后续已另建 [PPO 残差训练入口](regrasp-rl-baseline.md)，请区分两种运行器。V1 切菜环境、权重与入口没有修改。

## 运行

从仓库根目录，使用现有 `.venv` 和本地机器人资源：

```bash
# 无窗口，自动连续三次；失败返回非零退出码。
OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/run_regrasp_microskill.py

# 实时窗口，R 倒手一次，H 中止/保持，X 重置仿真。
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/run_regrasp_microskill.py --view

# 小范围随机尺寸与不规则凸形，导出视频和逐步结果。
MUJOCO_GL=egl OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/run_regrasp_microskill.py \
  --randomize-shape --seed 2 --video --output local/outputs/potato/regrasp_microskill/seed2
```

窗口加 `--auto` 会自动执行三次，然后保持。每个控制周期 20 ms，包含 10 次 2 ms 物理积分；计算慢时窗口会慢于真实时间，不丢弃动力学步。退出窗口后写入 `report.json`；无窗口运行结束时立即写入。输出包含形状参数、状态转换、接触载荷、最大物体位移和完成次数。

## 已实现

- 新模块 `twin_sim.regrasp_microskill`，独立于 `DynamicRegraspEnv`。从场景 XML 删除整个右臂、刀、对应驱动与引用，只保留左臂/手和桌面物体等。模型 27 个驱动器。
- 初态使用录制首帧作为关节种子，再求固定悬空目标：三指 z=326 mm。不根据随机土豆表面计算初始贴合位置；初始指尖间隙至少 5 mm。录制依赖仍为 `local/data/recordings/recorded_hand_guarded_chop_200hz_latest.npz`。
- 指尖下降由载荷反馈控制，各指独立停止压入/调整，三指载荷在 0.1–3 N 内持续 120 ms 才建立支撑。目标载荷 0.65 N 是仿真初值，未经硬件标定。
- 参考支撑阶段 1.2 s、腕部后退 4 mm；移指阶段 1 s，三指目标后移 8 mm、抬高最多 12 mm，DIP 从 30° 先屈至 54° 再伸回，手腕另退 4 mm，并在中途轻抬最多 5 mm，朝向始终固定。使用连续五次平滑插值。
- 移指前采样 51 个参考位姿做全段 IK 可达性预检；失败在抬指前报告，不强行执行。该预检不是动态碰撞/稳定性证明，实际动力学另行检查。
- 落指用反馈继续找表面，支撑成立后检查实际相对土豆的指尖后移误差在 3 mm 内、累计土豆位移小于 5 mm、物体线速度小于 20 mm/s。成功后保持；同一物体连续三次不 reset。第四次请求暂按保守工作区上限拒绝。
- IK 使用独立 scratch data；在线物理状态只由 `mj_step` 推进。关节目标限幅和单步增量限制保留原有限力驱动。故障或 HOLD 仍继续物理积分。
- 指令 ID 去重、忙时拒绝且不排队；下降时取消保持当前目标，移指时取消转入受控落指尝试，失败/超时明确报告。
- 键盘回调只有按下事件，采用 0.6 s 安静间隔抑制连续按键重复；这不是严格按下/松开边沿接口，快速重复点击可能被忽略。真实手柄接入尚未实现。

## 随机化与输入边界

默认形状沿用 V1：半轴 40×65×30 mm、削平底面 3 mm、质量 220 g。启用随机化后，三轴分别乘 0.95–1.05，按体积比例调整质量，同时改变平滑不对称形变的随机相位。种子可复现；连续三个请求不改变物体形状。

桌面实际高度 230 mm；配置的高度估计允许 ±3 mm，指尖中心下降边界为估计高度 +16 mm。它只用于下降限制，不能替代接触反馈。尚未对高度误差全范围完成验收。

`observation()` 提供关节位置、速度、目标误差、三指总法向载荷代理、执行器力矩代理和相对桌面的腕部位置。参考控制器使用理想接触载荷，没有使用土豆表面查询来决定下降终点。执行器力矩字段不是吴际实测电流，也还没有滤波/延迟标定。当前函数是调试用字典，尚不是冻结的 Gym observation contract。

精确物体位置用于结果验收，不是实机可用信号。局部指尖位置由关节几何求得。暂未加入反馈历史、非对称 actor/critic 或训练 reward。

## 验证与限制

```bash
OMP_NUM_THREADS=1 .venv/bin/python -m pytest tests/simulation/test_regrasp_microskill.py -q
```

首次检查 6 项通过：固定形状和随机种子 1/2/3 的悬空起始、三次连续请求与保持；无接触反馈不进入倒手；下降中止后可重新接近。检查无右臂、无初始接触、重复/忙时请求、物理时间连续和有限观测。小样本通过不代表任意形状泛化。

开发时最初第三次移指 IK 不可达，原因是固定 DIP 弯曲与高指尖轨迹限制了工作空间。用移指中途 5 mm 轻抬腕扩大余量，保留固定腕部方向；增加全段移指 IK 预检，避免执行到一半才发现名义轨迹不可达。

待继续完成：

- 当前支撑到移指是定时参考，不是设计中的中节角度/反馈决策；尚需调整初始手形与角度演变，再加入可靠触发。
- PIP/DIP 落指阶段没有复用 V1 的关节单调展开约束，需视觉检查与轨迹测量后继续优化。
- READY/HOLD 尚未分出 DISABLED/使能协议；真手柄边沿、断线与过期请求尚未接入。
- 取消后的空中落指、单指假接触、指间碰撞、桌面误差以及更广的形状分布需要进一步测试。过大载荷/物体移动会触发 FAULT，但还不是完整硬件保护。
- 新 Gym 环境、RL action/reward 与首轮训练已在[独立训练模块](regrasp-rl-baseline.md)中实现；本参考入口仍不用策略。Wuji effort 标定和 sim2real 尚未实现。

本版本用于先检查“无刀、悬空下降、反馈接触、三次连续倒手”的物理和交互基础，不应据此宣称阶段 B 的全部验收或 sim2real 已完成。
