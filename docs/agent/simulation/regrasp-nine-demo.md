# 九次退腕、三次移指：播放演示

2026-09-18。用户要求从悬空下降开始，每个指尖固定位置退腕三次，再同步移指，重复三轮。

## 实现

`MicroSkillConfig.support_repeats=3` 启用新节奏；默认仍为 1，之前参考动作和 PPO 训练入口不改变。每轮支撑退腕总量仍是 4 mm，分成三个约 1.33 mm 的平滑推进段，每段最后 25% 时间保持。三段总参考时长 2.4 s，由旧 PPO 的速度残差调整。随后三指同步后移 8 mm，伴随原有小幅腕部平移和抬升。

同一土豆上三轮物理连续执行，共九个退腕段、三次指尖重定位。初态与原新环境相同：悬空、没有接触，接触后才开始退腕。形状只在演示样本之间更换。

新的三段节奏与指尖固定假设仍由程序提供，不是本次新训练得到。加载的是 `regrasp_rl_v1/policy.zip`，仅执行已有的八维参数调整。移指前的 IK 预检和实际落点验收保留。

较长支撑时间下，种子 100 最初第三次落指误差略超过 3 mm。检查发现有限刚度下的指尖跟踪误差与土豆移动共同导致超限。只在三段模式把三根主指位置增益系数从 2.5 调为 3.5，阻尼按平方根同步缩放，执行器力上限保持不变；复测三个样本通过，没有放宽验收阈值。这是仿真参考控制调整，不是学习成果或真机标定结果。

## 生成与播放

```bash
# 导出种子 100、101、102 三段实际物理执行视频和逐步记录
MUJOCO_GL=egl OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/show_regrasp_nine.py

# 循环播放已导出视频，不在播放器里训练或执行实时控制
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/show_regrasp_nine.py --play
```

播放器提供上一个、下一个、重播、暂停/继续；空格暂停，左右方向键换视频。视频开头 1.6 s 是悬空初态的静止展示，之后播放 50 Hz 物理控制轨迹（视频 25 fps），末尾继续物理保持约 2 s。视频标题明确写明 `PPO residual + SCRIPTED 3 x 3 schedule (not retrained)`。

输出目录 `local/outputs/potato/regrasp_nine/`：`seed_100.mp4` 等视频和对应 JSON。每个 JSON 包含实际腕部/指尖位置、载荷、动作、阶段及九个 `WRIST_RETREAT_DONE` 参考段完成事件。计数由参考段进度产生，物理腕部仍有有限跟踪误差；回归检查实际每轮腕部后退超过 3 mm。

## 验证

种子 100、101、102 均完成三次落点验收和九段退腕；完成验收时的累计最大土豆位移分别为 3.611、1.702、2.217 mm。末尾额外两秒仍继续物理保持，画面位移计数继续更新，例如种子 100 最后一帧约 4.54 mm；JSON result 是完成验收时的快照。结果只覆盖这三个样本，且种子 100 接近落点容差，不能宣称新节奏已充分鲁棒。

新增回归验证九个事件按顺序发生、每次移指前恰有三个退腕段、实际腕部确有后退；同时运行原参考/Gym 测试确认默认模式保持可用，共 9 项通过（39.66 s）。

## 可自由调整视角的三维回放

```bash
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/view_regrasp_nine_3d.py
```

该入口根据三个 JSON 中保存的动作重新运行物理轨迹，并核对三次落指、九次退腕及最大物体位移，然后在 MuJoCo 中回放完整机器人状态。回放时写入 qpos/qvel 仅用于显示已验证轨迹，不是在线控制或训练。鼠标可旋转、平移、缩放；空格暂停，R 重播，1/2/3 切换样本。默认循环当前样本，切换样本时重建对应形状的查看器并保留相机视角，退出窗口则结束。
