# 双臂护手切菜

`guarded-chop` 由右臂持刀完成 5 刀，左臂和 20 自由度 Wuji Hand 在刀具低位时执行
开手、后退、合手，再由刀具斜向抬升换位。默认 `plane` 场景完成 4 次、共 80 mm
退手；`object` 保留为回归场景。

状态机保证刀运动时护手锁定、护手移动时刀具锁定，并检查刀刃到全部手部碰撞代理的
最小距离及真实接触。迁移后 headless 和 Viewer 均完成 5/5 刀、4/4 退手；headless
最小距离为 0.057 m。

`recorded-hand-guarded-chop` 将一段真实手势连续分成 5 段，与五刀共享时钟，不把整段
录制重复五遍。右刀随指垫区域移动，左腕连续退让；该流程已 headless 完成 5/5 刀与
5/5 手势段。它依赖被 Git 忽略的 MCAP，且只证明计划几何与仿真接触，不证明真机力控。

历史形成过程见[编年记录](../chronicles/2026-07-08-dual-arm-chopping.md)。
