# 土豆倒手：面向形状适配、抗扰和 sim2real 的下一步设计

> 范围已更新：用户随后选择先做不含切菜的独立倒手微技能。当前近期范围以 [微技能环境设计](regrasp-microskill-env-design.md) 为准；本文保留形状、抗扰与迁移的长期考虑，不作为第一阶段切菜联动实施要求。

2026-09-18。状态：**下一阶段设计提议，尚未实现或训练**。已认可的动作基线仍为 [V1 / 4b1928e](potato-regrasp-v1.md)；本文件不修改其运行逻辑。触觉硬件、观测频率和形状测量设备尚待确认，不能将下述传感输入视为已有真机能力。

## 1. 新目标与 V1 的差距

用户希望不同土豆形状对应不同的手位置，并在切菜施力时按稳土豆，最终迁移到真实机器人。

V1 目前的形状适配方式：

- `build_finger_regrasp_preview()` 内固定半径 `(0.040, 0.065, 0.030)`、初始摆放和若干接触点 X/Y。
- 根据网格距离竖直寻找指尖落点，用 `FingerSolver` 求关节目标；手掌位置有指定的偏移。
- 连续任务每轮固定后退 8 mm，支撑与落指腕后移分别为 4 mm。
- PPO 只输出三个竖直按压位置残差和参考时钟速度，不能选择接触区域、完整手掌摆位或不同后退幅度。
- actor 接收固定的三个半径与土豆真实位姿/速度，没有从实际观测重建形状。
- V1 无外力，刀保持在完整刚体土豆上方，因此现有成功率不说明抗切菜扰动能力。

只随机换一个网格再沿用写死的接触点，很可能得到不可达或无支撑的起始状态，也没有赋予策略选择接触位置的能力。需要同时修改环境生成、动作空间、观测和评估。

## 2. 拟采用的控制分工

保留 V1 用户认可的动作结构作为先验：三指同步，固定指尖时后退腕，起指屈曲、落指展开，不拧腕，左手完成后刀跟进。RL 负责在这个动作范围内根据形状与反馈选择可行的落点和用力配合。

| 能力 | 拟采用方式 |
|---|---|
| 形状/位姿表示 | 初期仿真提供可解释的几何描述或局部表面采样；最终 actor 必须能从真实相机/传感重建对应输入 |
| 初始接触位置 | 根据土豆表面生成宽松的可达候选范围，策略选择/调整掌部位置与三指接触区域；不把唯一最优姿态预先放进 reset |
| 保持支撑 | 策略连续调整各指关节或局部接触目标及有限的腕部平移，抵抗力和力矩 |
| 连续倒手 | 在抗扰保持学稳后，逐步增加移指长度、落点选择、推进时机的策略自由度 |
| 刀和左手互锁 | 初期继续用显式等待/接触判断；不要让尚未学稳的策略取消刀手避让和落稳条件 |
| 底层执行 | 限位、限速的关节位置目标，或真实设备支持且已验证的阻抗/力矩接口；不假定设备能直接接收指尖力命令 |

动作空间至少要让“掌部/接触区域位置”和“各指的按压姿态”可调。候选是小幅腕部平移 + 三指局部目标或关节协同参数 + 移指推进量；具体维数、尺度和控制频率在硬件接口与可达性试验后确定。不先把所有左右臂自由度都交给 RL，以免再次出现用拧腕替代倒手的行为。

如果只开放固定参考上的微小竖直偏差，应继续称为“抗扰按压残差策略”，不能宣称已经学到形状适配和落点选择。

## 3. 施力任务的定义

第一阶段训练的主任务为：三指已建立支撑时，对土豆施加具有变化方向、持续时间和作用点的扰动，策略通过接触反馈使物体保持稳定。

- 可先用连续推力、短脉冲与缓变载荷建立可重复的力学测试，不必先实现材料断裂。
- 切菜施力在偏离质心的点上，除了力 F 还产生力矩 `(作用点 - 质心) × F`。只在质心施水平推力不能覆盖该情形。
- 训练时分别随机力的方向、大小、时间形状、作用位置；范围先覆盖可实现的小扰动，再依据真机测量扩大，不凭空指定最终牛顿范围。
- 扰动随机源不得由策略时钟控制，以免策略通过快进/暂停规避扰动。记录实际物理时间和冲量。
- 真实切菜受力以后应测量力—时间曲线，用来校准等效载荷；“等效扰动下能稳定”和“真实切割能稳定”是两个验收层次。

三指同时腾空且辅助指移开时，没有原来三指的持续按压力。初期刀在这一阶段暂停施切菜载荷，延续已认可的互锁顺序；这不是证明移指阶段抗持续扰动。如果任务要求不断刀/持续受力，需要另行选择交替接触、辅助指、夹具等支撑方式，不能靠奖励要求 RL 克服缺失接触的物理限制。

## 4. 为 sim2real 设计 observation

采用“执行策略使用可部署观测，价值网络可使用特权真值”的方向；具体 PPO 实现需明确支持 actor/critic 不同输入，不能只是把同一个含真值字典送给两者。

| 输入 | 执行策略 actor | 训练 critic / 诊断 |
|---|---|---|
| 关节位置、可获得的速度 | 使用；包含真实采样和延迟约束 | 可使用真值辅助 |
| 触觉 | 使用拟部署传感器可输出的信号及短时历史 | 可使用理想力、接触位置等辅助 |
| 形状/位姿 | 视觉估计的表示，并模拟误差与遮挡；若暂用真值训练 teacher，需另做学生迁移 | 精确网格、物体状态 |
| 摩擦、质量、材料参数 | 不直接泄漏随机参数；必要时从历史反馈推断 | 可见真值 |
| 外力/外力矩 | 只有实机确实可测时才作为对应输入，否则由反馈体现 | 可见真值用于训练/分析 |
| 接触对象身份、精确滑移 | 不把仿真内部字段冒充传感器读数 | 可用于奖励和诊断 |
| 刀状态、允许动作阶段 | 控制器已知且实机能获得的状态 | 可见完整任务状态 |

现有 80 维触觉是十块接触区域的理想聚合量。若真机只有三个指尖传感器，应匹配三块区域；若传感器是触觉图像，需设计图像编码/特征提取，不能直接当成八通道力传感器。关节电流也不等同于指尖接触力，必须有标定和模型才能估计。

## 5. 训练顺序与 reward 原则

1. **多形状接触建立。** 随机长度、宽度、高度、平底比例、姿态和位置；既检查初始化可达率，也检查从预抓位置建立有效支撑的能力。不要静默丢弃难形状后只报成功率。
2. **固定接触抗扰。** 从稳定支撑开始，随机加载力和力矩，训练避免滑移/转动、减少恢复时间，并约束过大按压力与动作变化。
3. **连续三轮重新落点与抗扰。** 每次移指面对新的局部表面，重新接触后再承受扰动，检验不会只会第一轮。
4. **实机数据校准后的训练与迁移。** 先在真实可实现的观测和控制接口下验证，再扩大任务复杂度。

奖励重点：物体平移/旋转/速度小、扰动后恢复快、有效支撑、按计划完成接触区域后移；惩罚过大接触力、执行器饱和、关节抖动和刀手碰撞。几何参考只作弱先验或约束，不宜用很强的逐关节跟踪奖励把策略锁在旧形状姿态上。

需防止两种捷径：一直停着不倒手；用不现实的大按压力抵消全部扰动。阶段完成与受力稳定分别考核，并保持有限执行器能力。初期可继续用 PPO，但新观测/动作定义不能直接假定旧四维策略可复用。

## 6. sim2real 工作内容

在导出策略前完成，而不是等仿真训练结束后才考虑：

- 核实真实反馈通道、控制模式、频率、时间戳和延迟。
- 测量空载/接触情况下的位置跟踪、摩擦/回差、驱动力上限，拟合模型的相关参数。
- 测量指尖材料、土豆表面与砧板的接触特性；果蔬表面、削皮和含水情况可能改变接触，不能把单一库默认值当成标定结果。
- 围绕实测值及其不确定性随机化质量、摩擦、执行器增益/延迟、接触顺应性与测量误差。随机化不是越大越好，也不能替代检查错误模型。
- 先验证无刀接触建立和可控受力保持，再验证倒手及刀手时序，最后才评估真实切割；各阶段保留可比较的仿真与真机指标。

方法依据：MuJoCo 官方系统辨识文档描述了使用实测与仿真输出差异拟合摩擦、阻尼、质量、PD 参数及测量延迟的流程。该仓库 main 分支工具的接口并不代表当前安装环境已经验证可用，本提议只采用“先用数据识别模型”的方法，尚未集成其工具。

来源：[MuJoCo System Identification Toolbox](https://github.com/google-deepmind/mujoco/blob/main/python/mujoco/sysid/README.md)。

在灵巧手任务中，通过物理参数随机化在仿真训练并迁移到真机已有研究实例；它支持这条路线的可行性，不构成本项目无需校准或必然迁移成功的保证。

来源：[Learning Dexterous In-Hand Manipulation](https://arxiv.org/abs/1808.00177)。

## 7. 必须保留的对照与验收

- 冻结的 V1 和确定性几何接触控制器，作为非新策略对照。
- 相同形状、初始状态和扰动序列下，对比新策略与基线。
- 从训练阶段就移除触觉的对照，与相同训练预算的有触觉策略比较；仅评估时清零触觉属于分布扰动测试，不能代替公平消融。
- 分开报告“已见形状、未见形状、未见接触参数、未见扰动”的结果。形状/扰动种子与训练集合隔离。
- 报告接触建立成功率、三轮完成率、最大位移/转角、受力后恢复时间、滑移、接触力/执行器峰值、刀手碰撞及初始化不可达率。
- 真实机器人必须单独测量同类指标；漂亮视频或仿真 seed-100 成功不等于 sim2real 成功。

## 8. 待确认与可先做的工作

待确认：是否仍用当前 Wuji 左手；真实触觉硬件的覆盖区域、输出形式和频率；位置/速度/电流/力矩实际反馈接口；获取土豆形状的相机与估计方式；是否仍保留三指同时离开、此时刀暂停的顺序。

不依赖具体触觉硬件即可先做：把固定土豆配置/接触位置从 V1 生成器中分离，建立形状与可达性测试；建立可记录作用点、力矩、物理时钟的扰动任务；明确数据划分和验收指标。V1 保持独立回放与对照。

实现落点先后：形状参数化 → 几何可达初始化/候选区域 → 固定接触抗扰环境 → 确定可部署 observation/action → 新策略训练 → 连续倒手 → 实机辨识与迁移验证。确认硬件前，不冻结最终触觉编码或声称已完成训练/迁移。
