# cooking_proj 仓库呈现设计

## 目标

把当前几乎空白的仓库呈现成一个轻松幽默的“厨房杂物抽屉”：不虚构成熟功能，也不把项目包装成正式产品，明确说明 `main` 分支主要用于存放不太重要但舍不得删的零碎内容。

## README

- 全文使用中文。
- 采用简短、随意、有一点自嘲的语气。
- 包含仓库定位、可能出现的内容和一条轻量免责声明。
- 在开头展示仓库封面图。
- 不添加虚构的安装步骤、技术架构、徽章或路线图。

## `.gitignore`

提供与具体技术栈无关的基础规则，忽略：

- 操作系统生成的杂项文件；
- 常见编辑器和 IDE 的本地配置；
- 环境变量、日志和临时文件；
- 常见缓存、构建输出与依赖目录。

规则应保守，避免误伤可能有意提交的菜谱、图片和项目源码。

## 封面图

- 用途：README 顶部横版封面。
- 内容：温暖厨房台面上的菜谱便签、木勺、香料和一只略显随意的锅。
- 风格：轻松、温暖、有生活感的手绘插画。
- 构图：横向，主体分布自然，保留适量留白。
- 限制：不含文字、品牌标识或水印。
- 文件位置：`assets/kitchen-drawer.png`。

## Git 更新

完成后检查 Markdown 图片引用、Git 状态和最终差异；随后提交到当前 `main` 分支并推送至 `origin/main`。

## 验收标准

- README 能准确表达仓库的随意定位，且无不存在的功能描述。
- `.gitignore` 覆盖常见本地杂项且不过度忽略。
- 封面图已保存在仓库中，并能通过 README 的相对路径显示。
- 工作树最终干净，提交已推送到 GitHub。
