# Wuji 手套网络接入

本页迁移自旧项目 2026-08-26 的现场记录。示例设备和网卡只属于当时机器，执行前替换为
当前手套地址与实际有线接口。

历史示例：手套 `WG1JA03260502041`，Studio 地址 `192.168.10.150:50001`。先检查路由：

```bash
ip route get 192.168.10.150
ping -c 2 192.168.10.150
```

如果目标网段为 `192.168.10.0/24`，而专用有线接口没有同网段地址，可临时添加地址。下面的
`enp129s0` 必须替换成 `ip link` 确认的接口：

```bash
sudo ip address add 192.168.10.10/24 dev enp129s0
ip route get 192.168.10.150
ping -c 2 192.168.10.150
```

恢复修改：

```bash
sudo ip address del 192.168.10.10/24 dev enp129s0
```

修改网络需要管理员权限，且可能影响现有连接；不确定接口或地址是否冲突时不要执行。广播
扫描成功不代表定向 SDK 路由正确。连接手套遥操作前关闭 Wuji Studio，确认没有其他进程
拥有同一设备，并再次核对实体手序列号、手性和物理急停。
