# 土豆倒手：当前进展与开发交接

更新时间：**2026-09-19**。本说明核对的代码基线为 `4497280`（`ok`）；旧切菜 V1 基线为 `4b1928e`。本文是当前工作的入口，详细历史和公式通过文末链接查阅。

**当前已经实现独立无刀环境、参考控制器、PPO 残差训练，以及九次退腕/三次移指的三维回放。** PPO 确实训练过，但九次节奏尚未重新训练；动作顺序和基本轨迹仍由程序决定。没有连接或控制真机，也没有完成 sim2real。

## 1. 我们要解决什么

先把切菜简化为左手倒手微技能：

1. 土豆放在限定桌面区域，底部削平一小块；手从土豆上方悬空开始。
2. 手下降，依靠三根手指的接触反馈找到表面并建立支撑。
3. 指尖基本保持原位，手腕沿桌面固定方向后退。
4. 食指、中指、无名指同步收起、后移、展开，重新扣住土豆。
5. 可以在同一个土豆上连续执行，物体不能被手推走。

最终希望通过遥控器几个按钮调用技能，并迁移到真机。第一版不要求点云，不解决任意位置抓取，不包含右手、刀或切割。桌面高度是带误差的位置参考与下降边界，不能代替接触判断；手腕朝向固定，不通过拧腕完成动作。拇指、小指不参与夹持。

## 2. 当前“程序”和“RL”分别做什么

```text
悬空 → 下降 → 三指按稳
                 ↓
       固定指尖，手腕后退
                 ↓
       三指收起、后移、重新接触
                 ↓
       落点和稳定性验收 → 保持 / 下一轮
```

| 内容 | 当前负责人 |
|---|---|
| 阶段顺序、三指同步、固定方向和腕部朝向 | 程序 |
| 参考退腕/移指曲线、逆运动学与关节限幅 | 程序 |
| 是否接触、是否按稳 | 接触反馈与程序阈值 |
| 三指载荷目标、速度、抬指高度、DIP 弯曲幅度 | 参考默认值，或 PPO 输出调整 |
| 物体运动和关节实际运动 | MuJoCo 动力学 |
| 落点和稳定性验收 | 仿真状态检查，部分使用物体真值 |

这是**程序动作结构 + 学习参数调整**，不是从零学习完整关节动作。用户已接受这种分工。后续重点是证明学习调整在不同形状和反馈误差下有帮助，而不是仅把演示播放得顺滑。

特别注意：目前移指仍由参考退腕阶段完成触发，**尚未接入中节指骨接近垂直时的角度触发**。不能把旧切菜 V1 的角度控制能力直接算到新环境上。

## 3. 动作与物理设置

- 名义土豆半轴 40×65×30 mm，质量 220 g，底部削平 3 mm；名义外形约 80×130×60 mm，削平与不对称形变会改变实际高度。
- 随机化时三轴各乘 0.95–1.05，质量按体积缩放，改变平滑不对称形变的相位。使用不规则凸形碰撞，不支持真实凹坑。
- 同一个 episode 内形状不变；连续请求不重置土豆。没有焊接或固定物体。
- 初始三指目标中心高度 326 mm，桌面高度 230 mm；初态无接触。接触位置不根据随机土豆表面预先贴好。
- 三指载荷在 0.1–3 N 内持续约 120 ms，才建立支撑；参考目标载荷每指 0.65 N。它们是仿真参数，未经真机标定。
- 每轮固定指尖时退腕总计 4 mm；随后指尖后移 8 mm，同时腕部再后移 4 mm。移指中途指尖抬起约 12 mm，手腕轻抬最多 5 mm，腕部朝向不变。
- 移指前采样 51 个参考位姿检查 IK 可达性；这不等于证明动态接触一定稳定。
- 控制周期 20 ms，每次执行 10 个 2 ms 物理步；在线控制只改关节目标，IK 在独立 scratch data 中计算。
- 完成验收检查实际相对物体的指尖后移误差小于 3 mm、累计物体位移小于 5 mm、接触与物体速度满足条件。

### 九次演示的计数含义

`support_repeats=3` 时，每个指尖固定位置的 4 mm 退腕分成三段，每段约 1.33 mm，每段末尾短暂停留。三段之后移指 8 mm，再重复，最终 **九段退腕 + 三次指尖重定位**，不是九次完整重定位。

三段支撑参考总时长 2.4 s，PPO 可以调速度。计数表示参考退腕段完成；实际腕部仍有有限跟踪误差。默认 `support_repeats=1` 保留旧新环境的单段节奏。

## 4. RL 是怎么训练的

实现文件：[`regrasp_rl.py`](packages/cooking_simulation/src/twin_sim/regrasp_rl.py)。算法为 CPU PPO，网络 `[64,64]`，rollout 512，batch 128，学习率 3e-4，gamma .995，训练随机种子 0。

一个 episode 从悬空开始，同一物体连续完成三次移指。成功、故障或超时结束，再随机初始化下一回合。每步取得观测、输出动作并计算奖励；收集一批数据后更新策略网络。执行窗口不会自动继续训练。

### Observation：354 维

每帧 118 维，叠加最近三帧：

- 左臂和手共 27 个关节的位置、速度、目标误差：81 维。
- 三根主指的总法向接触载荷：3 维。
- 三指 12 个关节的执行器力矩代理：12 维。
- 腕部相对桌面的位置：3 维。
- 内部阶段 one-hot：9 维。
- 阶段时间与完成次数：2 维。
- 上次策略动作：8 维。

没有直接输入点云、土豆尺寸、表面、位姿或速度。当前 actor/critic 共用输入，没有实现特权 critic。物体真值用于奖励和完成判断；实机验收不能直接照搬。

当前载荷来自理想 MuJoCo 接触，力矩来自执行器输出，**不是已标定的 Wuji 电流/effort 信号**。测量噪声、滤波、延迟和硬件反馈映射尚未实现。

### Action：8 维

| 维度 | 内容 | 范围 |
|---|---|---|
| 0–2 | 三指载荷目标 | 0.4–0.9 N |
| 3 | 下降/找接触速度系数 | 0.7–1.3 |
| 4 | 支撑退腕速度系数 | 0.75–1.25 |
| 5 | 移指速度系数 | 0.75–1.25 |
| 6 | 腾空高度 | 10–14 mm |
| 7 | DIP 额外弯曲 | 20–28° |

动作经过平滑，最终转换为位置目标，不直接发送电流或牛顿指令。移指高度和弯曲幅度在进入腾空阶段时锁定，避免半途突然换曲线。零动作对应参考参数。

### Reward

鼓励建立支撑、实际完成后移和重新按稳；惩罚土豆位移/速度、过大接触力、动作变化、耗时、故障和超时。腾空阶段允许失去接触。具体系数见 [RL 设计](docs/agent/simulation/regrasp-rl-baseline.md) 和源码。

## 5. 已训练、已验证的结果

第一轮 **16,384 步 PPO** 已完成，训练用时约 **154.3 s**，针对的是每轮单段退腕的旧节奏。策略保存于 `local/outputs/potato/regrasp_rl_v1/policy.zip`。

| 种子 100–103，每回合三次移指 | 零动作参考 | PPO |
|---|---:|---:|
| 完成三次的回合 | 4/4 | 4/4 |
| 平均每回合最大土豆位移 | 1.2146 mm | 1.1201 mm |
| 平均执行时间，不含 reset | 14.405 s | 14.365 s |

两个形状上 PPO 略差，另两个更好。样本少、总体差异小，**不能据此证明稳定提升、触觉依赖或 sim2real 能力**。

九次退腕演示复用这份权重，**没有重新训练**。种子 100/101/102 均完成九段退腕和三次移指；完成验收时最大位移分别为 3.611/1.702/2.217 mm。末尾额外两秒保持仍继续积分，位移可能继续增加，例如种子 100 最后一帧约 4.54 mm。

最近一次参考/Gym/九次动作回归：**9 项通过，39.66 s**。三维回放还会根据保存动作重跑动力学，检查九次/三次计数与完成时位移，避免显示与记录不一致。

## 6. 怎么运行，以及怎样避免看错界面

以下命令从仓库根目录执行，依赖现有 `.venv`、本地机器人资产和录制首帧。

### 当前推荐：九次动作，可旋转三维视角

```bash
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/view_regrasp_nine_3d.py
```

这是 **3D PHYSICS REPLAY**，不是实时训练。鼠标左键旋转、右键平移、滚轮缩放；空格暂停，R 重播，1/2/3 切换三个土豆。默认循环当前样本。切换形状时重新打开查看器并保留视角，直接关窗口会退出。

它读取已有 `local/outputs/potato/regrasp_nine/seed_*.json` 动作记录，重跑物理轨迹，再回放机器人状态。回放时赋值 qpos/qvel 只用于展示，不代表控制器在执行时直接写物理位置。

### 其他入口

```bash
# 实时参考控制，不用 RL：R 请求一次，H 保持，X 重置仿真
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/run_regrasp_microskill.py --view

# 实时执行已训练 PPO：默认单段退腕节奏，自动三次，结束后保持
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/run_regrasp_rl.py \
  --policy local/outputs/potato/regrasp_rl_v1/policy.zip --view

# 重新生成九次演示的视频和动作记录
MUJOCO_GL=egl OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/show_regrasp_nine.py

# 二维视频播放器：不能旋转三维视角
DISPLAY=:0 OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/show_regrasp_nine.py --play

# 新训练：当前脚本默认仍是单段退腕，建议新输出目录避免覆盖首轮结果
OMP_NUM_THREADS=1 .venv/bin/python scripts/simulation/train_regrasp_rl.py \
  --steps 16384 --output local/outputs/potato/regrasp_rl_next

# 回归测试
OMP_NUM_THREADS=1 .venv/bin/python -m pytest \
  tests/simulation/test_regrasp_microskill.py tests/simulation/test_regrasp_rl.py -q
```

**训练脚本目前没有 `--support-repeats` 参数。** 要正式针对九次节奏重训，需要先把 `RegraspRLEnv(support_repeats=3)` 接到训练与评估配置，并把该配置写入模型元数据，不能以为再次运行上面的训练命令就会自动训练九次。

一次只开一个查看窗口即可。带刀的 `run_dynamic_regrasp.py` 是旧 V1；`run_regrasp_microskill.py` 是无 RL 参考版；`run_regrasp_rl.py` 才加载新策略；`view_regrasp_nine_3d.py` 是物理轨迹回放。

## 8. 遇到的问题与处理

- **第三次移指 IK 不可达**：固定 DIP 与较高抬指轨迹挤占工作空间。加入移指中途最多 5 mm 的轻微抬腕，保持朝向固定，并在抬指前预检整条参考曲线。
- **九次节奏第三次落点超差**：有限刚度下的手指跟踪误差与土豆移动叠加。仅三段模式将主指位置增益系数从 2.5 调到 3.5，阻尼同步按平方根缩放，原执行器力上限保留。未放宽 3 mm 落点验收。该调整未做真机标定。
- **动作看起来用了 RL，但主要由程序决定**：明确标注 residual，提供零动作参考对照；九次节奏不是新学习成果，不把参考动作流畅等同策略学会倒手。
- **多个界面混淆、视频无法转视角**：另建唯一用途的三维回放入口，并明确参考/策略执行/视频/三维回放的区别。

## 9. 尚未完成与后续开发

1. 把九次节奏、增益和动作配置接入训练/评估元数据，在相同配置下重训与对照。
2. 处理更广形状、桌面估计误差和姿态变化；当前只有小范围随机化和少量样本。
3. 若保留用户期望的角度条件，需要在新环境重新实现和验证，当前仍按参考阶段切换。
4. 接入真实 Wuji 反馈，验证 effort 信号、刷新率、延迟和内部阻力；仿真代理不能直接当硬件读数。
5. 通过反馈消融和受控扰动验证策略是否真正利用触觉。仅在当前 actor 隐藏载荷还不够，因为底层参考控制仍使用载荷。
6. 完成真实手柄边沿、断线、取消、使能协议，以及策略调用接口。现阶段只有参考键盘入口，尚无真遥控器闭环。
7. sim2real：系统辨识、观测噪声/延迟建模、部署接口和真实成功测量均待做。
